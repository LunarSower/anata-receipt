# ANATA RECEIPT

A thermal printer receipt simulation app. Print creative receipts with snap photos or custom items.

## Features
- Snap Receipt: halftone photo processing
- Custom Receipt: itemized receipts
- Printer simulation with paper feed animation
- Tear gesture: drag down or double-click to tear
- Receipt Stack: save and preview receipts
- B&W mode only

## Tech
- HTML / CSS / JavaScript (Canvas API)
- No dependencies
